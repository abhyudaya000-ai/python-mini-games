# Python Mini Games 🎮

A collection of beginner Python projects I built while learning programming and exploring how simple ideas can be turned into working games.

## 🎯 Projects

### 1. Rock Paper Scissors
A command-line Rock Paper Scissors game where the player competes against the computer.

**Features**
- Randomly generates the computer's choice
- Accepts player input
- Determines the winner or a draw
- Displays the result in the terminal

**What I learned**
- Using Python's `random` module
- Taking user input and processing strings
- Applying conditional statements to game logic
- Using loops and Boolean variables to control program flow

The idea of creating a Rock Paper Scissors game in Python came to me after watching a YouTube video. I implemented my own version to explore how the game's logic could work in code.

### 2. Tic-Tac-Toe
A two-player Tic-Tac-Toe game built using Python and Tkinter.

**Features**
- Interactive 3×3 game board
- Two-player gameplay
- Checks for winning combinations
- Highlights winning buttons

This project was inspired by a YouTube tutorial. It helped me explore graphical user interfaces, button interactions, and the logic required to detect a winning combination.

## 🛠️ Technologies

- **Python 3** — game logic and program flow
- **Random module** — computer choices in Rock Paper Scissors
- **Tkinter** — graphical interface for Tic-Tac-Toe

## 🚀 How to Run

Make sure Python 3 is installed on your computer.

Clone or download this repository, open a terminal in the project folder, and run the game you want to play.

**Rock Paper Scissors**
```
python rock_paper_scissors.py
```

**Tic-Tac-Toe**
```
python tic_tac_toe.py
```

Replace the filenames in these commands if your actual Python files have different names.
