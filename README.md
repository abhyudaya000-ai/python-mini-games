# Python Mini Games 🎮

A collection of beginner Python projects I built while learning programming and exploring how simple ideas can be turned into working games. These projects have helped me practise Python fundamentals, understand game logic, and experiment with graphical user interfaces.

## 🎯 Projects

### 1. Rock Paper Scissors

A command-line Rock Paper Scissors game where the player competes against the computer.

**Features**
- Randomly generates the computer's choice
- Accepts player input
- Determines the winner or a draw
- Displays the result in the terminal

**What I learned**
- Using Python's `random` module
- Taking user input and processing strings
- Applying conditional statements to game logic
- Using loops and Boolean variables to control program flow

The idea of creating a Rock Paper Scissors game in Python came to me after watching a YouTube video. I implemented my own version to explore how the game's logic could work in code.

### 2. Tic-Tac-Toe

A two-player Tic-Tac-Toe game built using Python and Tkinter.

**Features**
- Interactive 3×3 game board
- Two-player gameplay
- Checks for winning combinations
- Highlights winning buttons
- Displays a message when a player wins

**What I learned**
- Creating graphical user interfaces with Tkinter
- Working with buttons and user interactions
- Using lists to represent winning combinations
- Organizing game logic into functions

This project was inspired by a YouTube tutorial. It helped me explore graphical user interfaces, button interactions, and the logic required to detect winning combinations.

### 3. Snake Game 🐍

A Snake game built using Python and Tkinter, based on a YouTube tutorial. I followed the tutorial to understand the game's implementation and added a restart feature that allows the player to start a new game after a game over.

**Features**
- Grid-based game board
- Arrow-key controls
- Food collection and snake growth
- Collision detection with walls and the snake's own body
- Score tracking
- Restart functionality using the Space key after a game over

**What I learned**
- Using Tkinter Canvas to draw game elements
- Working with coordinates and movement
- Using classes and lists to represent game objects
- Implementing collision detection
- Understanding game loops and game states
- Modifying an existing implementation to add functionality

This project helped me understand how different Python concepts work together to create an interactive game. Adding the restart feature also gave me an opportunity to practise modifying code and managing game states.

## 🛠️ Technologies

- **Python 3** — game logic and program flow
- **Random module** — generating computer choices in Rock Paper Scissors
- **Tkinter** — creating graphical interfaces for Tic-Tac-Toe and Snake
- **Tkinter Canvas** — drawing the snake, food, and other game elements

## 🚀 How to Run

Make sure Python 3 is installed on your computer. Tkinter is included with many standard Python installations.

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the Python file for the game you want to play.

**Rock Paper Scissors**
```bash
python rock_paper_scissors.py
```

**Tic-Tac-Toe**
```bash
python tic_tac_toe.py
```

**Snake Game**
```bash
python snake_game.py
```

Replace the filenames in these commands with the actual filenames in your repository if they are different.
